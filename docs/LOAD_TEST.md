# Юклама ва тикланиш синовлари (T095, T092)

**Шароит (ҳақиқий ўлчов, production қуввати ҳақида кафолат эмас):** ONLINE-MAGAZIN-DEV сандбокс, 4 vCPU, 16 GB RAM; PostgreSQL 16.15 (default созламалар) ва API (`node dist/main.js`, битта процесс, pool 20) ва юк генератори **битта машинада**. Маълумот: `scripts/load/prepare.sql` — 10 000 фаол SKU, 100 000 тарихий буюртма (синтетик).

**Профил** (`scripts/load/run.mjs`, 60 с): 100 параллел «браузер» (кутиш вақтисиз, ёпиқ цикл: 40% каталог саҳифаси, 30% қидирув, 30% маҳсулот саҳифаси) + 10 параллел checkout цикли (маҳсулот → сават → quote → тасдиқ, 4 so'rov).

| Ўлчов | Оптимизациядан олдин | Кейин |
|---|---|---|
| Read throughput | 96 rps | **357 rps** |
| Read p50 / p95 / p99 | 956 / 1559 / 1720 ms | **245 / 505 / 591 ms** |
| Checkout цикли (4 so'rov) p50 / p95 / p99 | 3680 / 4430 / 4733 ms | **1050 / 1537 / 1875 ms** |
| Тугалланган checkout'лар | 167 | **560** |
| Кутилмаган хатолар (5xx/тармоқ) | 0 | **0** |
| Oversell (`reserved > on_hand`) | 0 | **0** |

**Топилган муаммо ва тузатиш:** қидирув ҳар қатор учун синоним subquery ва trigram'сиз regex ишлатар эди (90 ms/so'rov). Синонимлар олдиндан бир марта олинади; ҳар токен `LIKE` (pg_trgm GIN) + чегара regex текшируви; каталог агрегатлари `GROUP BY` билан ва фақат керакли саҳифа учун; индекслар қўшилди (0007).

**Мақсадга нисбатан:** read p95 мақсади ≤ 500 ms — кутиш вақтисиз 100 параллел клиентда **505 ms (чегарада, 1% ортиқ)**. Ҳақиқий браузер сессиялари кутиш вақтига эга бўлгани учун юк камроқ бўлади, аммо бу алоҳида ўлчанмаган. Хатолик < 1% ✓, oversell 0 ✓, duplicate payout — бу профилда payout йўқ (параллел payout тест билан текширилган: T078).
