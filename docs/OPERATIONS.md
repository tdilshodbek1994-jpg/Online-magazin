# Операцион қўлланма

## Кундалик оқим
1. **Оператор** (`/ops`): «Янги» навбат → «Олиш» → мижозга қўнғироқ → айнан жами суммани ўқиб «Тасдиқлади» (ёки «Жавоб бермади / Кейин / Рад этди»). Дубликат белгиси бўлса текширинг.
2. **Омбор** (`/ops` → «Йиғишга тайёр»): Йиғиш → Қадоқланди → Курьерга топшириш (курьер ID). Шу пайт қолдиқ ҳисобдан чиқади.
3. **Курьер** (`/courier`): Етказилди (тасдиқ коди) ёки Муваффақиятсиз уриниш; кун охирида нақдни «Кассага топшириш».
4. **Молия** (`/admin` → Молия): COD топшириғида **ҳақиқатда тушган** суммани киритинг. Фарқ бўлса exception очилади — изоҳ ва далилсиз ёпилмайди.
5. **Payout**: молия «Тайёрлаш» → бошқа ваколатли шахс «Тасдиқлаш» → банкда ўтказма → «Тўланди» + банк референси. Натижа номаълум бўлса «Натижа номаълум» — қайта ўтказма қилманг.
6. **Қайтариш**: оператор сўров очади → тасдиқ → омбор қабул (quarantine) → текширув (sellable/damaged) → молия refund (сўровчи ≠ тасдиқловчи).

## Runbook'лар
| Симптом | Биринчи амал |
|---|---|
| Тўлов олинган, буюртма `paid_no_stock` | `finance_exceptions` (late_payment_no_stock) → мижоз билан алтернатива ёки refund |
| `extra_payment` exception | иккинчи тўловни провайдерда текшириб, refund жараёни |
| `refund_unknown` / `payout_unknown` | провайдер/банк кўчирмасини текширинг; натижа аниқ бўлгач `result` endpoint; кўр-кўрона қайта юбормаслик |
| COD фарқи | курьер билан солиштириш, изоҳ билан exception ёпиш |
| Ҳамкор низоси | `partner_disputes` + `POST /admin/orders/:id/attribution` (сабаб + далил) |
| Комиссия available бўлмаяпти | тасдиқ/етказиш/тўлов settled/hold/очиқ қайтаришни текширинг; `POST /admin/commissions/release` |
