# 1-босқич: Эга + Ҳамкор (affiliate) савдо модели — мослаштириш режаси

**Сана:** 2026-11-02 · **Branch:** `claude/online-marketplace-platform-sdtv52` · **Ҳолат:** режа, батафсил ТЗ кутилмоқда

64 модулли тўлиқ маркетплейс иши **вақтинча тўхтатилди**. Ҳеч нарса ўчирилмади; ёзилган код шу
босқичга асос бўлади. MASTER ҳужжат (`docs/master/MASTER.txt`) мақсадли архитектура сифатида қолади.

## 1. 1-босқич мақсади

1. **Магазин эгаси** (ва ваколатли ходимлари) маҳсулот, нарх, қолдиқ жойлайди. Ҳамкор маҳсулот яратолмайди (MASTER D02 `owner_only`, AC-M01-1).
2. **Ҳамкор шахсий ҳавола/QR** орқали мижоз келтиради → мижоз ўзи буюртма беради → сотув ҳамкорга ёзилади.
3. **Ҳамкор мижоз номидан буюртма киритади** (assisted order) — фақат мижознинг тасдиқланган розилиги билан:
   ҳамкор draft тузади → мижозга SMS/ҳавола боради → мижоз товар, миқдор, жами сумма, етказишни кўриб **ўзи тасдиқлайди** (OTP) →
   шундан кейингина буюртма яратилади. Розилик далили (вақт, телефон, кўрсатилган сумма hash'и) сақланади (MASTER M39, AC-M39-2, INV06).
4. **Комиссия:** буюртма сатрида attribution ва комиссия қоидаси snapshot қилинади; ҳолатлар estimated → pending → available → paid;
   бекор/қайтаришда сторно (MASTER M29–M31, 9.3: 100 000 → 30 000; 40 000 қайтса → 12 000 сторно).

## 4. Мослаштириш қадамлари (тасдиқдан кейин бошланади)

1. **Асосни тузатиш:** identity TS хатолари, етишмаган модуллар учун stub'ларни олиб ташлаб, `app.ts`ни 1-босқич модулларига қисқартириш; API компиляция ва ишга тушиши.
2. **Миграция 0006_affiliates:** affiliates, affiliate_links, click_events, assisted_order_drafts (+ consent evidence), commission_rule_versions, commission_accruals/adjustments, affiliate_balances, payout_requests.
3. **Каталог + қолдиқ** (эга учун CRUD, мижоз учун кўриш/қидирув).
4. **Сават → quote → буюртма (COD)** + атомар резерв; ҳамкор attribution snapshot.
5. **Assisted order** оқими ва мижоз тасдиқ саҳифаси.
6. **Комиссия ҳисоби** (delivered бўлганда pending→available, hold муддатидан кейин), бекор/қайтаришда сторно.
7. **Payout** сўрови ва тасдиқлаш.
8. **Web:** витрина, сават/checkout, мижоз кабинети, ҳамкор кабинети (ҳавола, сотувлар, даромад, payout), эга/админ панели.
9. **Тестлар (реал PostgreSQL):** охирги товарга 100 параллел checkout; 20 такрорий callback; 30 000 комиссия; 40 000 қайтаришда 12 000 сторно; payout collision (400 000 + 300 000 / 500 000); ҳамкор бошқа ҳамкор маълумотини ололмайди; мижоз тасдиғисиз assisted order яратилмайди.
10. **Docker Compose, GitHub Actions CI, ҳисобот, Pull Request.**
